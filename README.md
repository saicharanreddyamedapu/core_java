# Core Java

This repository contains Java programs and practice exercises focused on core Java concepts. It is designed for learning, understanding, and implementing Java fundamentals through hands-on coding.

## About

Core Java is the foundation of Java programming. It covers the essential building blocks of the language, including:

- Variables and data types
- Operators and control statements
- Classes and objects
- Inheritance and polymorphism
- Encapsulation and abstraction
- Exception handling
- Collections
- Multithreading
- File handling
- Packages and access modifiers

Prerequisites
Before running Java programs in this repository, make sure you have:

Java Development Kit (JDK) installed
A Java IDE such as IntelliJ IDEA, Eclipse, or VS Code
Git installed for version control
Installation
Install JDK 8 or later.
Set up Java environment variables if required.
Clone the repository:
bash
git clone https://github.com/saicharanreddyamedapu/core_java.git
cd core_java
How to Compile and Run
To compile a Java file:

bash
javac FileName.java
To run the compiled program:

bash
java FileName
Example:

bash
javac HelloWorld.java
java HelloWorld
Example Program
Java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Welcome to Core Java!");
    }
}
